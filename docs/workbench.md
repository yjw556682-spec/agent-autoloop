# 网页工作台

工作台使用 Agent Autoloop 的本人接口，可以接入此仓库安装的中台或官方 1.8.2。旧中台继续负责派单、调度、执行和通知，工作台使用已有的规则与运行记录。

## 打开工作台

1. 用 Node.js 24 或更新版本运行。先用 **agent-autoloop doctor** 检查原中台。中台应监听 **127.0.0.1**。
2. 在仓库目录执行 **node scripts/workbench.ts**，打开终端显示的完整链接。Windows 可执行 **powershell -NoProfile -ExecutionPolicy Bypass -File scripts/open-workbench.ps1**。
3. 如已有中台装在自选目录，用 **AGENT_AUTOLOOP_HOME** 指向含 **config.json** 的目录。默认使用用户目录下的 **.agent-autoloop**。工作台默认使用本机端口 **3351**，可用 **AUTOLOOP_WORKBENCH_PORT** 选择空闲端口。
4. 完整链接包含本次工作台进程的临时会话密钥，请留在本机。网页打开后地址栏会自动清掉它。重新启动工作台后，请重新打开会话。前台运行时按 Ctrl+C 可关闭工作台。

仓库已包含网页构建产物。修改网页源码时，运行 **npm ci** 和 **npm run build**。

## 在网页里操作

- **运行总览**显示待处理、运行中、排队及重试、今日完成和用量。谱线和运行列表都能打开详情。运行列表支持筛选和读取更早的记录。运行详情包含触发事件、经过与停止操作。
- **待你处理**显示等候答复或结案的卡片。可以点选答案、输入其他回复或填写结案原因。同一张卡片只处理一次，飞书和网页走同一套中台状态。
- **规则与来源**显示事件来源、下次运行时间、暂停状态与定时复查。可以运行已有规则、暂停或恢复。连接支持补跑的中台时，恢复一条有跳过事件的规则后可以选择补跑。
- **手动事件**由包含本人来源的规则接收。此分支的中台支持网页发射，官方 1.8.2 的工作台通过已有规则运行或配置好的专用提交入口接单。
- **大屏**适合在另一块屏幕看状态，点击谱线回到总览中的对应详情。

工作台的本机入口只转发页面使用的本人接口。浏览器使用临时会话密钥，中台密钥由本机工作台读取。规则、配置、业务材料和运行记录都应留在各自的私有数据目录。

## 高校实训营链接

Windows 上已有实训营规则及 **Submit-Bootcamp.ps1** 时，在打开命令后加 **-Bootcamp**，或用 **node scripts/workbench.ts --bootcamp**。提交脚本位于 Autoloop 的数据目录，接受 **-Link** 和可选的 **-PlanLink**，通过已有飞书登录读取任务或方案。提交卡接受单个飞书任务链接或方案链接。任务包含多个方案时填写具体方案。草稿保存在该规则配置的本机目录，供本人审核。

## 按需启用场景

[场景模板](../README.md#拿来即用的场景模板)提供定时简报、网站巡检、告警、反馈、GitHub Issue、飞书简报和浏览器交接。每个模板都说明需要的规则、来源、执行器、通知通道和运行命令。先把所需配置放入 Autoloop 的私有数据目录，填入对应环境里的地址和授权，再运行 **agent-autoloop check**。规则生效后会出现在工作台。其他执行器和通道参见[插件说明](plugins.md)。
